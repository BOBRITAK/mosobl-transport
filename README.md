# Транспорт Подмосковья
Публикация GitHub Pages: загрузить содержимое этой папки в корень репозитория, открыть Settings, Pages, Deploy from a branch, main, root. Сайт статический, без ключей, платных API и сервера, все пути относительные, работает на телефоне и компьютере. Данные: data/lines.json и data/stations.js.
