# Транспорт Подмосковья

Статический сайт: карта и схема метро, МЦК, МЦД D1–D4 и проектируемых линий метро Подмосковья.
Поиск станций, построение маршрутов, два режима отображения — «География» (карта с подложкой) и «Схема».
Без сервера, без API-ключей, без сборки: обычные HTML/CSS/JS, публикуется на GitHub Pages.

## Что показывает

| Слой | Состав |
|---|---|
| Метро | 15 линий, включая БКЛ, Бутовскую и Некрасовскую |
| МЦК | Московское центральное кольцо (замкнутое) |
| МЦД | D1, D2, D3, D4 |
| Проектируемые | 15 радиальных линий в Подмосковье (см. оговорку ниже) |

Электрички, обычные станции OSM и автобусные остановки из интерфейса удалены: остались только
перечисленные виды транспорта.

## Два режима

**География** — карта Leaflet с подложкой CARTO Dark (запасной источник — OSM), линии проходят
по реальным координатам.

**Схема** — топологическая схема в духе Яндекс.Метро: линии идут под углами, кратными 45°,
станции стоят на равных интервалах, кольца замкнуты, пересадки собраны в узлы. Геометрия схемы
лежит в `data/scheme_layout.json` и пересчитывается скриптом:

```
node tools/build-scheme.mjs      # пересчитать схему
node tools/preview-scheme.mjs    # посмотреть схему текстом (ASCII)
node tools/check-layout.mjs      # проверить интервалы между станциями
```

Как считается схема (см. `tools/build-scheme.mjs`):

* у каждой линии свои копии станций, поэтому цепочку всегда можно уложить точно под 45/90°;
* копии одной станции стягиваются пружинами — так получаются пересадочные узлы;
* вся раскладка — задача наименьших квадратов, решается плотным Холецким (система маленькая,
  решение точное);
* направления и длины пересчитываются 18 итераций, затем станции слегка расталкиваются.

Текущее качество раскладки: среднее отклонение от 45° — 2.6°, 55 % отрезков в пределах 1.5°,
пересадочные копии сходятся в среднем на 2.6 единицы. Это автоматическая раскладка: она близка
к ручной схеме, но не заменяет работу дизайнера.

## Структура

```
index.html            разметка интерфейса
css/app.css           оформление, адаптив (панель слева / нижняя панель на телефоне)
js/main.js            связка: поиск, маршрут, слои, режимы, карточка станции
js/network.js         загрузка данных и нормализация сети
js/mapview.js         карта Leaflet: подложка, линии, станции, подписи, маршрут
js/schemeview.js      режим «Схема»: отрисовка топологической схемы, зум, подписи
js/router.js          граф (станция + линия) и алгоритм Дейкстры
data/lines.json       действующая сеть: координаты OSM, порядок станций по линиям
data/project_lines.json  проектируемые линии (схематичные коридоры)
data/scheme_layout.json  готовая геометрия схемы (генерируется tools/build-scheme.mjs)
tools/                сборка и проверка схемы
vendor/leaflet/       Leaflet 1.9.4 локально, без CDN
sw.js                 service worker: HTML — сеть, данные и код — кэш с обновлением
```

## Локальный запуск

Открывать через файл нельзя: данные загружаются `fetch`, а ES-модули требуют HTTP.

```
python -m http.server 8000
# затем http://localhost:8000/
```

или любой другой статический сервер.

## Публикация

GitHub Pages: Settings → Pages → Deploy from a branch → `main` → `/ (root)`, файл `.nojekyll` уже в репозитории.
Сайт разворачивается в подпапке (`/mosobl-transport/`), все пути относительные — это учтено.

Service worker отдаёт HTML по принципу «сначала сеть», поэтому обновления доезжают до браузера сразу.
После первого деплоя новой версии возможен один лишний F5: старый service worker уже держит предыдущий
HTML в кэше и меняется на новый только после установки.

## Оговорки по данным

* Координаты действующих линий — из OpenStreetMap, порядок станций взят из открытых списков линий и
  сверен по координатам.
* **Проектируемые линии — схематичные коридоры, не официальный проект.** Трассировка и промежуточные
  станции приблизительные, привязка к районам реальная. Файл `data/project_lines.json` устроен просто:
  название, цвет, статус и список станций с координатами — правки не требуют изменения кода.
* Время маршрута расчётное: скорости по видам транспорта, время на пересадку и ожидание заданы
  константами в `js/router.js`.
