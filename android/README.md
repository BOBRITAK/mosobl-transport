# Android-приложение «Транспорт Подмосковья»

Самостоятельное нативное приложение: **Kotlin + Jetpack Compose**. Не WebView и не обёртка сайта.

Живёт в этом же репозитории рядом с сайтом, в папке `android/`.

## Быстрый старт

```bash
cd android
./gradlew :app:assembleDebug
# APK: app/build/outputs/apk/debug/app-debug.apk
```

Требуется JDK 17 и Android SDK (platform 34, build-tools 34.0.0).

## Тесты

```bash
./gradlew :app:testDebugUnitTest
```

17 тестов: 14 на маршрутизацию (направления, участки, совпадение карты и текста,
сценарий «Окружная», 8 сценариев поездок, пересадки) и 3 рендер-теста
интерфейса на JVM (Robolectric + Roborazzi).

## Что внутри

| Экран | Содержимое |
|---|---|
| Карта | тайлы Esri Dark Gray + собственный Canvas-оверлей: линии, станции, подписи, жесты |
| Схема | Canvas-схема из `scheme_layout.json`, три уровня разведения станций по зуму |
| Поиск | по названию, городу и линии; фильтры слоёв (метро, МЦК, МЦД, проектируемые) |
| Карточка станции | фото и описание из Википедии, город, линии, пересадки и пешие переходы, ★, «Отсюда»/«Сюда» |
| Маршрут | до трёх вариантов, этапы с направлением движения, пошаговая инструкция |
| Избранное и история | SharedPreferences, переживают перезапуск |

## Данные

Данные проверенного сайта лежат в `app/src/main/assets/` (150 КБ) и работают офлайн:

* `lines.json` — метро (15 линий), МЦК, МЦД D1–D4;
* `project_lines.json` — 24 проектируемых направления Подмосковья;
* `cities.json` — справочник городов;
* `scheme_layout.json` — геометрия схемы (45°/90°).

РЖД, электричек и МЦД-5 в приложении нет — это проверяется тестом.

## Сборка релиза

```bash
cd android
./gradlew :app:assembleRelease   # нужен keystore, см. app/build.gradle.kts
```
